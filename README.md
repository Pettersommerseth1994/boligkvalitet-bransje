# Boligkvalitet bransje

Klikkbar prototype av Husbankens e-søknad om grunnlån for bransje
(eiendomsutviklere og boligutviklere). Ren HTML, CSS og JavaScript, uten
backend og uten byggesteg.

Publisert på <https://pettersommerseth1994.github.io/boligkvalitet-bransje/>.

## Kjør lokalt

```bash
python3 -m http.server 4321
```

Åpne så <http://localhost:4321/grunnlan-esoknad/>.

## Innhold

- `grunnlan-esoknad/` – prototypen. Se [grunnlan-esoknad/README.md](grunnlan-esoknad/README.md).
- `ds/` – farger, typografi, Inter-fonten og Husbanken-logoene som prototypen bruker.
